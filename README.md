# PaperRealm 纸境

PaperRealm 是一款面向 Windows 的沉浸式 TXT 阅读器，旨在把本地文字收藏整理成可自定义的阅读空间。

[English introduction](README.en.md)

## 功能介绍

- **本地书库**：导入 TXT 文件，管理书籍、收藏、阅读进度与章节。原始文件不会被阅读器直接修改。
- **专注阅读**：支持单栏、双栏和连续滚动，目录、全文搜索、书签、摘录与批注帮助回到阅读位置。
- **阅读外观**：调整字体、字号、行距、字距、正文尺寸、背景配色和纸张纹理；阅读画面亮度可在外观设置中调节。
- **阅读桌面与书籍工坊**：切换书桌氛围，调整书籍封面和装帧风格。
- **语言与字体**：提供九种界面语言选项，按语言分类选择字体；部分界面翻译为机器生成，仍待校对。
- **辅助阅读**：支持系统语音朗读、简繁转换，以及可选的 DeepSeek 翻译。基础阅读可离线使用；DeepSeek 翻译需要网络和用户自己的 API 密钥，并会将所选文本发送至所配置的服务。
- **阅读记录**：保存阅读位置、书签、摘录及阅读统计，并提供数据导出。

## 使用方式

安装 Windows 版本后导入 TXT，在书库中打开书籍。阅读时打开“阅读外观”可以调整排版、纸张和阅读亮度；在“设置中心”可切换界面语言。

## 当前限制

多语言翻译尚需人工校对，部分动态提示可能仍为中文。阿拉伯语已加入 RTL 界面与正文处理，但复杂双向混排尚未完整验证，阿拉伯语正文使用普通翻页。语音效果取决于 Windows 已安装的语音。字体及第三方资源遵循各自许可；本项目不会将改造或重新封装的开源字体宣称为原创字库。
