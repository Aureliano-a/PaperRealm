# Windows development

Install Node.js, pnpm, the stable Rust MSVC toolchain, Visual Studio C++ Build Tools, and WebView2.

- Run `pnpm install --frozen-lockfile` in the repository.
- Run `pnpm desktop` for the desktop development build.
- Run `pnpm bundle` for a Windows NSIS installer.

The installer is written to the Rust target directory under `release/bundle/nsis`. The app builds its local PDF engine resources during the frontend build.
