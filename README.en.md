# PaperRealm

PaperRealm is an immersive Windows TXT reader designed to turn a local text collection into a personal, customizable reading space.

[中文介绍](README.md)

## Features

- **Local library:** Import TXT files, organize books and favorites, and return to saved reading positions and chapters. Reading does not directly modify the original files.
- **Focused reading:** Choose single-column, two-column, or continuous scrolling layouts. Navigate using the table of contents and full-text search; save bookmarks, excerpts, and notes.
- **Reading appearance:** Adjust typeface, font size, line and character spacing, text area, colors, and paper textures. The reading view also has an adjustable brightness control.
- **Desk and book studio:** Change the reading-desk atmosphere and customize book covers and binding styles.
- **Languages and fonts:** Nine interface language options and language-grouped fonts are available. Some interface translations were generated by machine and still need review.
- **Reading assistance:** Use system text-to-speech, simplified/traditional Chinese conversion, and optional DeepSeek translation. Basic reading works offline. DeepSeek requires a network connection and your own API key, and sends selected text to the configured service.
- **Reading history:** Save reading positions, bookmarks, excerpts, and statistics, and export reading data.

## Getting started

Install the Windows application, import a TXT file, and open it from the library. Use the reading appearance panel to adjust typography, paper and brightness. Change the interface language in Settings.

## Current limitations

Translations need human review and some dynamic messages may remain in Chinese. Arabic has RTL interface and text handling, but complex bidirectional text has not been fully validated and Arabic books use standard page turns. Available speech voices depend on Windows. Fonts and third-party resources retain their respective licenses; adapted open-source fonts are not represented as original typefaces.

Source code and installers have not yet been uploaded to this repository; this page currently describes the project.
