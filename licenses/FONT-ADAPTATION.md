# PaperRealm QingKai 字体说明

这两份 WOFF2 文件是基于 LXGW WenKai Regular 的有限派生版本，不是从零设计的原创字库。

版权来源与 SIL OFL 1.1 全文位于同目录 LXGW-OFL.txt。上游项目：https://github.com/lxgw/LxgwWenKai 。上游版权包括 LXGW 与 Klee Project Authors；保留其原始版权信息。派生作品以 PaperRealm QingKai 与 PaperRealm QingKai Elegant 命名，遵守上游 Reserved Font Names 限制。

生成脚本 scripts/build-fonts.py 使用 FontTools，实际改变简单轮廓的横向尺度与字形 advance / sidebearing：正文 98% 横向、12 单位字距；雅致 96% 横向、36 单位字距。复合轮廓结构保留。字符覆盖源自上游，读取到 46,926 个 Unicode 映射。并未逐字人工审校，不宣称具备独立字体设计师设计的完整原创字形。

上述派生字体继续以 SIL OFL 1.1 分发。不能单独出售字体。修改或再分发时须同时保留版权与 OFL。雅宋和静黑使用用户系统字体，不随本安装包分发微软字体文件。
