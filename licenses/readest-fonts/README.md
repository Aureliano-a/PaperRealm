# 阅读字体及许可

本目录保留新增阅读字体的版权与许可。字体文件是各上游发布的原始文件，未修改字形。它们在纸境内按需载入并可离线使用。字体列表参考 Readest 0.12.16 的公开字体配置；本程序不包含其代码。

Google Fonts 上游：Bitter、Fira Code、Literata、Merriweather、Noto Sans、Open Sans、Roboto、Vollkorn、PT Sans、PT Serif、PT Mono、LXGW WenKai TC、Noto Sans SC、Noto Sans TC 和 Noto Serif JP 均按各自 OFL.txt 分发；Roboto Slab 按其 Apache-2.0 许可分发。思源宋体 SC 来自 Adobe Source Han Serif，遵循 OFL。霞鹜文楷 GB 屏幕版来自 LXGW WenKai Screen，遵循对应 OFL。原俠正楷 T 来自 Tony Huang 的 GuanKiapTsingKhai v1.20，使用原字体并保留其名称与版权；本目录包含其版权、保留名称、OFL、上游声明及其底层字体许可。

MiSans、汇文明朝体和京华老宋体的字体软件未与本程序分发；若用户电脑已安装，程序可以在本机识别并使用它们。原俠正楷 T 根据字体本身的设计将部分简体字形显示为繁体字形，并不修改源文件。

Readest 字体配置：https://github.com/readest/readest/blob/v0.12.16/apps/readest-app/src/styles/fonts.ts
